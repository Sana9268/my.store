📱 Mobile Phone Store

A responsive Mobile Phone Store website that allows users to explore smartphones, view their specifications, and calculate their order total. This project is developed using **HTML, CSS, and JavaScript** to practice web development concepts and interactive website functionality.

✨ Features

- Responsive Design: Adjusts the layout for mobile and desktop screens.
- Light/Dark Mode: Switch between light and dark themes.
- Product Listings: Display different smartphones with their prices and descriptions.
- Phone Specifications: View phone details in a table.
- Category Filtering: Filter phones by Apple, Samsung, Google, or view all products.
- Order Total Calculator: Select multiple phones and automatically calculate the total price.
- Customer Form: Enter customer information, including name and email.
- Age Verification: Check eligibility for student and senior discounts.
- Read More / Read Less: Expand or hide additional store information.
- Dynamic Store Status: Display whether the store is currently open or closed.
- Character Counter: Show the remaining characters allowed in order notes.
- Table Row Highlighting: Highlight table rows when hovering over them.

🛠️ Technologies Used

- HTML5: For website structure and content.
- CSS3: For styling, layout, dark mode, and responsive design.
- JavaScript: For DOM manipulation, event handling, calculations, and interactive features.

🚀 How to Run the Project

1. Clone this repository:git clone https://github.com/sana/MobileStore.git

2. Open the project folder:cd MobileStore

3. Make sure the following files are present:
   MobileStore/
   ├── index.html
   ├── style.css
   ├── script.js
   └── README.md


4. Open `index.html` in your web browser.

5. Explore the products and try the interactive features.
